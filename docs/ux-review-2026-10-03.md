# Введение UX-стандарта: проверка пяти сценариев

Дата: 3 октября 2026 года. Исполнитель: Codex; экспертная проверка агентом, без участников пользовательского исследования.

## Область изменения

Исходная версия — `1de1a76` в `main`. Добавлены [UX_RULES.md](../UX_RULES.md), [реестр NN/g](nng-research.md), связи в инструкциях и шаблон описания PR. Содержание, HTML, стили, скрипты, шрифты и пользовательские взаимодействия не изменялись.

Все пять intent-level заданий из [DESIGN_EVALS.md](../DESIGN_EVALS.md) рассмотрены на принятом исходнике: совместимы ли новые требования с задачей, что уже проверяется и какое свидетельство ещё нужно. Это проверка исходной реализации и согласованности инструкций, не эксперимент генерации пяти новых вариантов интерфейса. Отдельные UI-патчи и временный worktree не создавались.

## Автоматические свидетельства

- `pnpm run check`: пройден. Четыре теста редакционных данных, актуальность сборки, шрифт, структура страницы, локальные ресурсы, performance budget и синтаксис проверены.
- `pnpm run test:browser`: 85 пройдено, 2 штатных пропуска проверки hover на мобильных проектах; всего 87. Desktop Chromium, mobile Chromium и mobile WebKit. Включены существующие проверки reflow 320 px, увеличенного текста, тем, reduced motion, согласия, обеих стопок, первого экрана и axe.
- Начальный запуск браузерного набора в sandbox не смог открыть локальный порт; повторный запуск с разрешённым локальным сервером прошёл. Это ограничение среды, не дефект сайта.
- Никакого нового автоматического теста, который лишь проверяет наличие слов в стандарте, не добавлялось. Смысловая оценка остаётся обязанностью ревью.

## Браузерное свидетельство

Открыта публичная версия [shirokostup.site](https://shirokostup.site/?review=nng-20261003) в настоящем Chrome. Осмотрены первый экран, переход Selected work, проект и его подпись, граница биографии и Reading room, контакт и весь футер. Выполнена смена кадров обеих стопок, открытие Index и выход через Escape с возвращением фокуса. Просмотрены System при тёмной системе, ручные Light и Dark, а также Reduced motion. При ширине 390 и 320 px осмотрен футер, на 320 px проверен клавиатурный фокус ссылки Dinamo и раскрытие Image credits.

Скриншоты и дерево доступности сохранены в инструментальных результатах чата. Автоматическая матрица дополняет этот осмотр: реальный iPhone, ручная проверка экранным диктором, свежий количественный замер контраста каждого пикселя градиента и полный пользовательский тест в эту работу не входили. Нельзя описывать их как пройденные.

## Решение

Стандарт принят как обязательная документация по прямому запросу владельца. Его внедрение не является заявлением, что интерфейс получил пять новых оценок Accept: у исходного сайта остались явно записанные Concern. Они сохранены в [реестре открытых вопросов](nng-research.md), вместе с планом проверки на посетителях.

Новая визуальная версия не выпускалась. Для следующей UI-задачи выбирается релевантный сценарий и выполняется полный применимый порог доступности и визуальной проверки; исторические ограничения этого обзора не становятся разрешением их пропустить.
